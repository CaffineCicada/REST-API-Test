# Feature 1 — Contact Management

## Quick Start
```
npm install
npm run dev
```

Then open **HOW_TO_TEST.md** for step-by-step testing instructions (with Windows PowerShell commands).

## Why sql.js instead of better-sqlite3?
`better-sqlite3` requires C++ build tools (Visual Studio) to install on Windows.
`sql.js` is pure JavaScript — no build tools needed, works everywhere.
